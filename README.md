# Bank Customer Churn Analysis | End-to-End Data Analytics Project

## 📌 Overview
A complete data analytics pipeline built on a Bank Customer Churn dataset, covering data cleaning, SQL querying, machine learning classification, and interactive Tableau dashboards to predict and analyze customer churn.

## 🛠️ Tech Stack
- **Python** (Pandas) – Data Cleaning & Preprocessing
- **SQL** – Data Querying & Aggregation
- **Machine Learning** – SVM, Random Forest (Classification)
- **Tableau** – Interactive Dashboard & Data Storytelling

## 📂 Project Files
| File | Description |
|------|-------------|
| `Paython.ipynb` | Data cleaning: missing values, duplicates, data type fixes |
| `SQL.sql` | SQL queries: joins, aggregations, filtering, subqueries |
| `ML.ipynb` | Classification models (SVM & Random Forest) to predict churn |
| `Tableau.twbx` | Interactive dashboard with KPIs, maps, and charts |

## 🔍 Key Steps
1. **Data Cleaning:** Handled missing values, removed duplicates, fixed data types
2. **SQL Analysis:** Country-wise churn count, average balance, filtered queries
3. **Machine Learning:** Built and evaluated SVM & Random Forest classifiers (Accuracy, Confusion Matrix, Classification Report)
4. **Visualization:** Built a Tableau dashboard with KPIs, geographic map, and churn distribution charts

## 📊 Dashboard Highlights
- Country-wise churn count & customer balance
- Credit Score vs Balance relationship
- Overall churn rate KPI (20.37%)
- Interactive filters by Country

## 🎯 Key Insight
France has the highest customer count, balance, and churn rate among all countries in the dataset.
